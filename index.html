Aprende los elementos esenciales de programación mediante ejemplos sencillos relacionados con mediciones ambientales.

Variables y tipos de datos

Una variable almacena un dato que puede utilizarse durante el programa.

Ejemplo · variables.py

Condicionales y ciclos

Los condicionales permiten tomar decisiones; los ciclos repiten instrucciones.

Ejemplo · control.py
ph = 5.2

if ph < 6.5:
    print("Muestra ácida")
elif ph <= 8.5:
    print("Dentro del intervalo ilustrativo")
else:
    print("Muestra alcalina")

temperaturas = [15, 17, 19]
for valor in temperaturas:
    print(valor, "°C")

Aplicación: revisar muchos registros y clasificarlos según criterios definidos.

El intervalo de pH del ejemplo es didáctico. La evaluación normativa del agua depende de su uso, categoría y regulación aplicable.
03 · Organiza información

Manejo de datos ambientales

Los archivos CSV y Excel suelen contener registros de monitoreo. La biblioteca Pandas permite leerlos, ordenarlos y calcular estadísticas descriptivas.

Leer un archivo CSV

lectura_csv.py
import pandas as pd

datos = pd.read_csv("monitoreo.csv")

print(datos.head())
print(datos.describe())
print(datos.isnull().sum())

04 · Comunica resultados

Análisis y visualización

Los gráficos ayudan a reconocer patrones, comparar periodos e identificar valores máximos y mínimos. Matplotlib es una biblioteca muy utilizada para crear visualizaciones en Python.

Gráfico de temperatura

grafico.py
import matplotlib.pyplot as plt

meses = ["Ene", "Feb", "Mar", "Abr"]
temperaturas = [14, 14.5, 14, 13]

plt.plot(meses, temperaturas, marker="o")
plt.title("Temperatura mensual")
plt.xlabel("Mes")
plt.ylabel("Temperatura (°C)")
plt.grid(True)
plt.show()

¿Cómo interpretar?

  • Identifica la tendencia general: aumenta, disminuye o se mantiene.
  • Ubica los valores máximos y mínimos.
  • Compara periodos equivalentes.
  • Revisa unidades, escala y calidad de los datos.
  • Explica qué significa el patrón en el contexto ambiental.
Un gráfico muestra patrones, pero por sí solo no demuestra la causa de un cambio ambiental.

06 · Laboratorio de aprendizaje

Practica con datos ambientales

Modifica los valores y observa cómo cambia el resultado. Esta pequeña calculadora demuestra la lógica de un programa Python.

Calculadora de reciclaje ♻️

El porcentaje de reciclaje aparecerá aquí.

¿Qué hace el programa?

indicador.py
generados = 200
reciclados = 80

if generados > 0:
    porcentaje = (reciclados / generados) * 100
    print(porcentaje, "%")
else:
    print("Revisa los datos")

Con los valores iniciales, el resultado es 40 %. La calculadora de esta página ejecuta la misma operación en el navegador mediante JavaScript; el código Python se muestra para que puedas reproducirlo en Google Colab.
